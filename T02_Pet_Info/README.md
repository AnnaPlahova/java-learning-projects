# "Pet Info"

Учебный проект на Java для отработки ООП, функционального и многопоточного программирования. Состоит из 6 модулей, каждый из которых реализует отдельный набор техник и подходов.

Каждый модуль оформлен в виде отдельного проекта.

## Технологии и ключевые навыки

- Java Core (Java 17+)   
- ООП: абстрактные классы, интерфейсы, инкапсуляция, полиморфизм   
- Коллекции: `List<T>`, работа с разнородными объектами   
- Обработка исключений и валидация ввода без аварийного завершения   
- Stream API и функциональный стиль   
- Многопоточность: `Thread`, синхронизация через `join()`   
- Паттерн «Итератор» (собственная реализация)   

## Задания

- Задание 1. Список питомцев   

Модуль составляет список питомцев и выводит информацию о каждом питомце.   
Использованные технологии и подходы:   
 - ООП: абстрактный класс, наследование, инкапсуляция (private-поля + геттеры), переопределение методов (toString)    
 - Коллекции: List<Animal> для хранения питомцев    
 - Работа с консольным вводом: Scanner, обработка исключений при парсинге чисел    
 - Валидация входных данных (тип питомца, возраст) без аварийного завершения программы    
 - Утилизация ресурсов: try-with-resources для автоматического закрытия Scanner

- Задание 2. Определение количества корма питомцу   

Mодуль по типу питомца определяет, сколько граммов корма ему необходимо на 1 порцию.   
Использованные технологии и подходы:   
 - ООП: абстрактный класс с абстрактным методом (getFeedInfoKg), наследование, переопределение методов   
 - Расчётная логика в классах-наследниках (Dog, Cat) по заданным формулам   
 - Коллекции: List<Animal> с полиморфным выводом через переопределённый toString()    
 - Обработка ввода и валидация: тип питомца, возраст, масса, некорректный парсинг чисел через NumberFormatException с повторным вводом      
 - Форматированный вывод вещественных чисел (с двумя знаками после запятой)
 - Парсинг строк: Integer.parseInt и Double.parseDouble — чтение строки целиком с последующим преобразованием

- Задание 3. Списки травоядных и всеядных питомцев   

Mодуль сначала выводит только травоядных животных, а затем только всеядных животных.   
Использованные технологии и подходы:    
 - Интерфейсы: Herbivore (метод chill()), Omnivore (метод hunt()) — как контракты для группировки животных по типу питания
 - Наследование и реализация интерфейсов: Dog, Cat реализуют Omnivore; Hamster, GuineaPig — Herbivore; все наследуются от абстрактного Animal
 - Полиморфизм: все питомцы в едином списке List<Animal>, раздельный вывод травоядных и всеядных через instanceof без приведения типов
 - Фабричный метод: createAnimal со switch по типу питомца, isValidPetType для предварительной валидации
 - Обработка ввода: валидация типа (4 варианта), возраста (age <= 0), некорректного парсинга чисел через NumberFormatException   

- Задание 4. Увеличение возраста конкретных питомцев в функциональной парадигме    

Mодуль увеличивает возраст питомцев старше 10 лет, придерживаясь функциональной парадигмы.   
Использованные технологии и подходы:   
 - Функциональный стиль: отсутствие циклов, использование Stream API (map) для трансформации коллекции
 - Неизменяемость: при увеличении возраста создаётся новый объект, исходные объекты не изменяются
 - Лямбда-выражения: в map и forEach — тернарный оператор внутри лямбды для условного создания нового объекта
 - Рекурсия вместо циклов: ввод количества, питомцев и обработка некорректного парсинга реализованы через рекурсивные вызовы (соблюдение запрета на операторы повторения)
 - Фабричный метод: createAnimal со switch для создания объектов по типу питомца

- Задание 5. Отслеживание прогулок питомцев   

Mодуль отслеживает время начала и завершения прогулки питомца.   
Использованные технологии и подходы:   
 - Многопоточность: каждый питомец гуляет в отдельном потоке (new Thread), запуск через thread.start()
 - Синхронизация: ожидание завершения всех потоков через thread.join() перед завершением программы
 - Работа со временем: System.nanoTime() для расчёта времени старта и окончания прогулки относительно старта программы
 - Имитация прогулки: вычисление длительности по формулам (Dog: age * 0.5, Cat: age * 0.25) и задержка через sleep внутри goToWalk()
 - Задержка между запусками: Thread.sleep(100) в основном потоке для обеспечения разницы во времени старта прогулок (не более 1 секунды между питомцами)
 - Обработка прерываний: перехват InterruptedException с восстановлением флага через Thread.currentThread().interrupt()
 - Форматирование вывода: String.format("%.2f", ...) для времени старта и финиша с округлением

- Задание 6. Итератор питомцев   

Модуль реализует итератор питомцев.   
Использованные технологии и подходы:   
 - Паттерн «Итератор»: собственный generic-интерфейс BaseIterator<T> с методами next(), hasNext(), reset()
 - Реализация итератора: класс AnimalIterator с private-полями списка и индекса, конструктор для инициализации
 - Управление состоянием итерации: инкремент индекса в next(), сброс через reset(), защита от выхода за пределы через NoSuchElementException
 - Проход по коллекции: через while (iterator.hasNext()) с вызовом iterator.next() вместо стандартного foreach
 - Инкапсуляция: private-поля списка и индекса, доступ только через методы интерфейса
