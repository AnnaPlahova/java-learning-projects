# Project T02 "Pet Info"

Проект представляет собой набор модулей для отображения информации о питомцах.

В этом проекте рассматриваются ООП/процедурные/мультипарадигмальные подходы в Java, написание кода в соответствии с функциональной парадигмой, а также асинхронное/параллельное программирование.

Каждое задание оформлено в виде отдельного проекта.

- Задание 1. Список питомцев
Модуль составляет список питомцев и выводит информацию о каждом питомце.
- Задание 2. Определение количества корма питомцу
Mодуль по типу питомца определяет, сколько граммов корма ему необходимо на 1 порцию.
- Задание 3. Списки травоядных и всеядных питомцев
Mодуль сначала выводит только травоядных животных, а затем только всеядных животных.
- Задание 4. Увеличение возраста конкретных питомцев в функциональной парадигме
Mодуль увеличивает возраст питомцев старше 10 лет, придерживаясь функциональной парадигмы.
- Задание 5. Отслеживание прогулок питомцев
Mодуль отслеживает время начала и завершения прогулки питомца.
- Задание 6. Итератор питомцев
модуль реализует итератор питомцев.
